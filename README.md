# Commercehub Microservices

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE) [![Contributions Welcome](https://img.shields.io/badge/Contributions-Welcome-brightgreen.svg)](CONTRIBUTING.md)


Enterprise-grade E-Commerce platform built with Spring Boot Microservices architecture, RabbitMQ messaging, API Gateway, MySQL, Redis, Load Balancing, Service Registry, and Angular frontend.

## Backend

- Spring Boot

- Spring Cloud Eureka Server
- Spring Cloud Gateway

# 🔄 Service Discovery

This project uses **Spring Cloud Eureka Server** for service registration and discovery.

Benefits:
- Dynamic service registration
- Load balancing support
- Fault tolerance
- Easy scalability
- Decoupled architecture
